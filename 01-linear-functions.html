Solving Simultaneous Linear Equations Graphically

Two linear equations plotted on the same axes: the point of intersection is the solution.

  1. Rearrange each equation into $y = mx + c$.
  2. Plot both lines accurately.
  3. Read the intersection point.
  4. Verify by substitution.

Compare gradients: same gradient + different intercepts = parallel (no solution); same gradient + same intercept = identical (infinite solutions).

Section 2

Solving Simultaneous Linear Equations Algebraically

Algebra gives a precise solution without drawing a graph. Two standard methods: substitution and elimination.

Solve: $2x + 3y = 12$ and $x - y = 1$.

  1. From $x - y = 1$: $x = y + 1$.
  2. Substitute: $2(y + 1) + 3y = 12$.
  3. $2y + 2 + 3y = 12 \Rightarrow 5y = 10 \Rightarrow y = 2$.
  4. Then $x = 3$.

Solution: $(3, 2)$

Solve: $2x + 3y = 12$ and $x - y = 1$.

  1. Multiply $x - y = 1$ by $3$: $3x - 3y = 3$.
  2. Add to $2x + 3y = 12$: $5x = 15 \Rightarrow x = 3$.
  3. Then $y = 2$.

Solution: $(3, 2)$ — the two methods agree.

The same system by both methods — 2x + 3y = 12 and x − y = 1 meet at (3, 2).

  • Same gradient, different intercepts → no solution.
  • Same gradient, same intercept → infinite solutions.
  • Otherwise → one unique solution.

Guided practice

  1. Solve $3x + y = 7$ and $2x - y = 8$ using elimination.
  2. Solve $y = 4x - 1$ and $2x + 3y = 22$ using substitution.

Use substitution when one variable already has coefficient 1. Use elimination when coefficients line up nicely for adding or subtracting.

Check gradients before doing any working: if they match, you already know the type of answer.

Section 3

Modelling Real-Life Situations Using Linear Functions

A linear model is written as $y = mx + c$. Each symbol carries real-world meaning:

SymbolMeaningExample
$m$Rate of changeCost per item, speed
$c$Initial valueFixed fee, starting amount
$x$Independent variableNumber of items, time
$y$Dependent variableTotal cost, distance

A taxi charges \$5 fixed plus \$2 per km: $C(d) = 2d + 5$.

  • $m = 2$: \$2 per km.
  • $c = 5$: \$5 fixed fee.
  • For 10 km: $C(10) = 2(10) + 5 = \$25$.

Taxi fare model — change the rate, the fixed fee and the distance; the readout computes the cost.

Guided practice

  1. A plumber charges \$60 callout plus \$45 per hour. Write the cost model and find the cost of a 3-hour job.
  2. Line $L_1$ has gradient $-3$. find the gradient of a line perpendicular to $L_1$.
  3. Write the equation of the line through $(0, 4)$ and $(5, 14)$.

The rate $m$ is multiplied by the variable; the initial value $c$ is added ($+$) or subtracted ($-$) as a fixed amount.

For perpendicular lines, multiply the two gradients: you should always get $-1$. A vertical line has no gradient, so it has no perpendicular partner of this form.
