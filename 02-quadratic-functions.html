Section 1

The Three Forms of a Quadratic Function

Every quadratic function can be written in three equivalent forms. Each form reveals different features of the parabola, and converting between them is a core skill.

$$f(x) = ax^2 + bx + c$$

  • $c$ = the $y$-intercept.
  • $a$ = direction and width.
  • Axis of symmetry: $x = -\frac{b}{2a}$.

$$f(x) = a(x - p)(x - q)$$

  • $p, q$ = the $x$-intercepts.
  • Axis of symmetry: $x = \frac{p + q}{2}$.

$$f(x) = a(x - h)^2 + k$$

  • $(h, k)$ = the vertex (max or min).
  • Axis of symmetry: $x = h$.

Converting between forms

ConversionMethod
Standard → FactoredFactorise
Standard → VertexComplete the square
Factored → StandardExpand
Vertex → StandardExpand

Example: $x^2 - 6x + 5 = (x - 3)^2 - 4$.

Guided practice

  1. Write $f(x) = x^2 + 8x + 7$ in factored and vertex form.
  2. From factored form $f(x) = 2(x - 1)(x + 3)$, state the $x$-intercepts and the axis of symmetry.

Factored form answers "where does it cross the axis?", vertex form answers "where is its maximum or minimum?", and standard form is what algebra normally produces.

In $(x - h)^2$, the vertex's $x$-coordinate is $+h$: $(x - 4)^2$ has vertex at $x = 4$, not $-4$.

Sketching routes

From vertex form: plot $(h, k)$, draw axis $x = h$, find $y$-intercept, use symmetry, find $x$-intercepts, sketch.

From standard form: axis $x = -\frac{b}{2a}$, substitute to find vertex, $y$-intercept $(0, c)$, factorise or use the formula for $x$-intercepts, sketch.

From factored form: plot $(p, 0)$ and $(q, 0)$, axis $x = \frac{p+q}{2}$, substitute the midpoint for the vertex, find $y$-intercept, sketch.

Guided practice

  1. For $f(x) = -x^2 + 6x - 5$, state direction, vertex, intercepts, maximum value, and range.
  2. Which parabola is narrower: $y = 3x^2$ or $y = 0.5x^2$? justify.

The vertex always lies on the axis of symmetry. Once you have the axis, substitute its $x$-value into $f$ to get the vertex's $y$-value.

$a > 0$: range is $f(x) \ge k$. $a < 0$: range is $f(x) \le k$. State it with inequality notation.

Section 3

Transformations of Quadratic Functions

The base function is $f(x) = x^2$. Every transformation of it can be read directly from the function's form.

TransformationFormEffect
Vertical translation$f(x) + k$Up / down
Horizontal translation$f(x - h)$Right / left
Reflection in $x$-axis$-f(x)$Flips upside down
Vertical dilation$af(x)$Stretch / compress
Horizontal dilation$f(bx)$Compress / stretch

$2(x - 3)^2 + 1$ compared to $y = x^2$:

  • Vertical stretch by factor $2$.
  • Right $3$.
  • Up $1$.

Combined form: $f(x) = a(x - h)^2 + k$.

Drag a, h, k to change the parabola — the grey y = x² reference stays put.

In $af(b(x - h)) + k$, work on the input first (horizontal shift, then dilation), then on the output (dilation, then shift).

Changes inside the brackets act on $x$ (horizontal, reversed feel). Changes outside act on $y$ (vertical, direct).

Section 3 Extended

General Transformations of Functions

The same rules apply to any base function $y = f(x)$, not just quadratics.

TransformationFormEffect
Vertical translation$y = f(x) + k$Up if $k > 0$, down if $k < 0$
Horizontal translation$y = f(x - h)$Right if $h > 0$, left if $h < 0$
Reflection in $x$-axis$y = -f(x)$Flips upside down
Reflection in $y$-axis$y = f(-x)$Flips left–right
Vertical dilation$y = af(x)$Stretch if $|a| > 1$, compress if $0 < |a| < 1$
Horizontal dilation$y = f(bx)$Compress if $|b| > 1$, stretch if $0 < |b| < 1$
Combined$y = af(b(x - h)) + k$All transformations

Let $f(x) = 2x + 1$.

  • $f(x) + 3 = 2x + 4$: up $3$.
  • $f(x - 2) = 2x - 3$: right $2$.
  • $-f(x) = -2x - 1$: reflect in the $x$-axis.
  • $f(-x) = -2x + 1$: reflect in the $y$-axis.
  • $2f(x) = 4x + 2$: vertical stretch by $2$.
  • $f(2x) = 4x + 1$: horizontal compression by $\frac{1}{2}$.

To shift right by 2 you subtract 2 inside: $f(x - 2)$. Dilation inside also inverts: $f(2x)$ compresses, not stretches.

For any function with an asymptote, apply the same vertical shift to the asymptote when translating.

Section 4

Range Given Domain, Composite & Inverse Functions

Determining the range on a restricted domain:

  1. Identify the domain.
  2. Find the vertex.
  3. Check if the vertex is inside the domain.
  4. Evaluate the endpoints.
  5. Determine the highest and lowest $y$-values.

$f(x) = (x - 2)^2 + 1$, $0 \le x \le 5$.

  • Vertex $(2, 1)$: minimum $y = 1$.
  • $f(0) = 5$, $f(5) = 10$.
  • Range: $1 \le f(x) \le 10$.

$f(x) = (x - 2)^2 + 1$, $3 \le x \le 5$.

  • Vertex at $x = 2$ is outside.
  • $f(3) = 2$, $f(5) = 10$.
  • Range: $2 \le f(x) \le 10$.

Slide the left endpoint of the domain — watch the range update.

$$(f \circ g)(x) = f(g(x))$$

Apply $g$ first, then feed the result into $f$. In general $f(g(x)) \ne g(f(x))$.

Let $f(x) = x^2 + 1$ and $g(x) = 2x - 3$.

$f(g(x)) = (2x - 3)^2 + 1 = 4x^2 - 12x + 10$: vertex $(1.5, 1)$, opens upward.

$g(f(x)) = 2(x^2 + 1) - 3 = 2x^2 - 1$: vertex $(0, -1)$, opens upward.

To graph a composite: make a table of $x$, evaluate $g(x)$, feed it into $f$, and plot $(x, f(g(x)))$.

For $f(g(x))$ to be valid: $x$ must be in the domain of $g$, and $g(x)$ must be in the domain of $f$.

Example: $f(x) = \sqrt{x}$, $g(x) = x - 3$ gives $f(g(x)) = \sqrt{x - 3}$, defined for $x \ge 3$; while $g(f(x)) = \sqrt{x} - 3$, defined for $x \ge 0$.

If $f(a) = b$, then $f^{-1}(b) = a$. Method: write $y = f(x)$, swap $x$ and $y$, solve for $y$.

Example: $f(x) = 2x + 3 \Rightarrow f^{-1}(x) = \frac{x - 3}{2}$. If $f(x) = x^2$ for $x \ge 0$, then $f^{-1}(x) = \sqrt{x}$ for $x \ge 0$.

Guided practice

  1. For $f(x) = x^2 - 6x + 10$ on $1 \le x \le 6$, determine the range.
  2. If $f(x) = 3x - 5$ and $g(x) = x + 2$, find $f(g(4))$ and $g(f(4))$.
  3. Find $f^{-1}(x)$ for $f(x) = \frac{x + 4}{2}$.

On a restricted domain you must check both endpoints and the vertex. The vertex may not be part of the domain at all.

$f \circ g$ means "do $g$, then $f$". Reading left to right: $(f \circ g) = f$ after $g$.

When finding an inverse, restrict the domain first if the function is not one-to-one (like $y = x^2$).

Section 5

Solving Quadratic Equations & the Discriminant

Three algebraic methods: factorising, the quadratic formula, and completing the square.

Solve $2x^2 - 4x - 6 = 0$:

  1. $x^2 - 2x - 3 = 0$ (divide by 2).
  2. $(x - 3)(x + 1) = 0$.
  3. $x = 3,\ -1$.

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

For $2x^2 - 4x - 6 = 0$: $x = \frac{4 \pm \sqrt{16 + 48}}{4} = \frac{4 \pm 8}{4}$, so $x = 3,\ -1$.

Solve $x^2 - 6x + 5 = 0$:

  1. $(x - 3)^2 - 4 = 0$.
  2. $(x - 3)^2 = 4$.
  3. $x - 3 = \pm 2$, so $x = 5,\ 1$.

$$\Delta = b^2 - 4ac$$

$\Delta$Nature of roots
$\Delta > 0$Two distinct real roots
$\Delta = 0$One repeated real root
$\Delta < 0$No real roots

$x^2 + kx + 9 = 0$ has one repeated root. Then:

$$\Delta = k^2 - 36 = 0 \Rightarrow k = \pm 6$$

Move a, b, c — the live Δ readout tells you whether the roots are real and distinct, equal, or none.

Guided practice

  1. Solve $3x^2 - 5x - 2 = 0$ by factorising and check with the formula.
  2. For what values of $k$ does $x^2 + 2x + k = 0$ have no real roots?

Factorise when the factors are obvious. Formula always works. Complete the square when you also want the vertex form.

A quadratic can have $0$, $1$, or $2$ real roots. Check the discriminant before committing to an answer count.

Section 6

Linear–Quadratic Systems & Finding Quadratic Equations

A line and a parabola can meet in $0$, $1$, or $2$ points. Substitute the line into the quadratic and solve.

Solve $y = x + 1$ and $y = x^2 - 1$.

  1. $x + 1 = x^2 - 1$.
  2. $x^2 - x - 2 = 0$.
  3. $(x - 2)(x + 1) = 0$, so $x = 2,\ -1$.
  4. Intersections: $(2, 3)$ and $(-1, 0)$.

Graph of Example 10 — y = x + 1 and y = x² − 1; the intersections are computed live.

Through $(0, 3)$, $(1, 0)$, $(3, 0)$:

  1. $y = a(x - 1)(x - 3)$.
  2. $3 = a(-1)(-3) = 3a$, so $a = 1$.
  3. $$y = x^2 - 4x + 3$$

Vertex $(2, -1)$, through $(0, 3)$:

  1. $y = a(x - 2)^2 - 1$.
  2. $3 = 4a - 1$, so $a = 1$.
  3. $$y = (x - 2)^2 - 1 = x^2 - 4x + 3$$

Guided practice

  1. Find the intersection points of $y = 2x - 3$ and $y = x^2 - 4x + 1$.
  2. A parabola has $x$-intercepts at $x = -2$ and $x = 4$ and passes through $(0, -8)$. Write its equation.

Substituting the linear equation into the quadratic always produces a quadratic in $x$. Its discriminant tells you how many intersections exist.

In factored form you already know $p$ and $q$; one extra point is enough to solve for $a$. In vertex form, you know $(h, k)$ and again only need one extra point.

Section 7

Quadratic Modelling & Optimisation

When a quadratic opens downward ($a < 0$), its vertex is the maximum: the classic optimising tool for height, profit, area, and revenue problems.

$h(t) = -5t^2 + 20t + 1$.

  1. $t = -\frac{20}{2(-5)} = 2$.
  2. $h(2) = 21$.
  3. Maximum height $= 21$ m at $t = 2$ s.

$P(x) = -2x^2 + 80x - 300$.

  1. $x = -\frac{80}{2(-2)} = 20$.
  2. $P(20) = 500$.
  3. Maximum profit $= \$500$ at $x = 20$.

Example 13: maximum height 21 m at t = 2 s — the dashed lines mark the vertex.

Optimisation recipe

  1. Define variables and build the quadratic model.
  2. Check $a < 0$ (maximum) or $a > 0$ (minimum).
  3. Axis: $x = -\frac{b}{2a}$.
  4. Evaluate the function at that $x$.
  5. Interpret the answer in the context.

Guided practice

  1. A rocket has height $h(t) = -5t^2 + 40t + 2$. Find the maximum height and the time it occurs.
  2. A rectangular field is bounded by $100$ m of fencing on three sides. Write the quadratic model for the area and find the width that maximises it.

The axis of symmetry is the average of the two roots, which works out to $-\frac{b}{2a}$ in every quadratic.

State that $t = 2$ s followed by "maximum height of 21 m" is a complete answer; a bare coordinate is not.

Section 8

Non-Linear Inequalities

Method for quadratic inequalities: find the critical values, build a sign table, and read off the solution interval(s).

Solve $x^2 - x - 6 > 0$.

  1. $(x - 3)(x + 2) > 0$; critical values $x = 3,\ -2$.
  2. Sign table:
IntervalTest $x$Sign
$x < -2$$-3$Positive
$-2 < x < 3$$0$Negative
$x > 3$$4$Positive

Solution: $x < -2$ or $x > 3$.

Sign of f(x) shown on the x-axis: teal where f(x) > 0, red where f(x) < 0.

Solve $|2x - 1| < 5$:

$$-5 < 2x - 1 < 5 \Rightarrow -2 < x < 3$$

Solve $|x + 1| \ge 3$:

$$x \le -4 \quad \text{or} \quad x \ge 2$$

Solve $(x + 1)(x - 2)(x - 3) \le 0$. Critical values $x = -1,\ 2,\ 3$.

  • $x < -1$: negative.
  • $-1 < x < 2$: positive.
  • $2 < x < 3$: negative.
  • $x > 3$: positive.

Solution: $x \le -1$ or $2 \le x \le 3$.

Solve $\frac{x - 1}{x + 2} > 0$. Critical values $x = 1$ and $x = -2$; note $x = -2$ is excluded.

  • $x < -2$: positive.
  • $-2 < x < 1$: negative.
  • $x > 1$: positive.

Solution: $x < -2$ or $x > 1$.

Guided practice

  1. Solve $x^2 - 7x + 10 \le 0$.
  2. Solve $|3x + 2| \ge 8$.
  3. Solve $(x + 2)(x - 1)(x - 4) > 0$.

You cannot divide an inequality by $x$ or by a denominator that may be negative — use sign analysis instead, and always exclude values that make a denominator zero.

Multiplying or dividing both sides of an inequality by a negative reverses the sign. A classic slip that costs the whole answer.
